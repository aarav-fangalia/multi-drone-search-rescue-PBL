# Phase III: Multi-Drone Search and Rescue

## Project Overview
This project simulates a multi-drone search and rescue system for dynamic disaster response using graph-based path planning and priority-based task allocation.

## Objectives
- Improve mission allocation based on priority.
- Determine routes between locations using graph algorithms.
- Handle blocked routes and drone failures in the simulation.
- Monitor drone battery levels and availability.
- Test and improve the reliability of the existing C++ implementation.

## Current Implementation
The project is implemented as a menu-driven C++ console simulation. Existing features include graph traversal, shortest-path calculation, mission prioritization, and simulated drone events.

## Phase III Work Plan
- Review and fix remaining menu-related bugs.
- Validate mission assignment and route-planning behavior.
- Test edge cases involving blocked routes, low battery, and drone failures.
- Update project documentation and record test results.
- Identify limitations and possible future enhancements.

## Testing
Testing results will be documented after the corresponding test cases have been executed and verified.

## Limitations
The current project is a software simulation. Physical drone deployment and real-world rescue testing are outside the scope of the current implementation.
